# Nina Galindo — Portfolio

A responsive, single-page portfolio for Nina's front-end and full-stack job search.

## Personalize it

- Replace `nina@example.com` in `dist/index.html` with your real email address.
- Add your own handwriting font as `dist/nina-handwriting.woff2`. The site already loads it for the hero and section headings.
- Replace project descriptions and links in `dist/index.html` as your work evolves.
- Edit colors in the `:root` section at the top of `dist/styles.css`.

## Run locally

Open `dist/index.html` in a browser, or serve the `dist` folder with any static web server.

## Files

- `dist/index.html` — page content
- `dist/styles.css` — design and responsive layout
- `dist/script.js` — mobile navigation and current year
